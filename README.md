# 🚀 From Beginner to Problem Solver

### DSA & Competitive Programming Roadmap for Juniors

A curated collection of resources shared during the **Junior Guidance Session** to help students start their programming journey, build strong problem-solving skills, learn DSA, and gradually enter Competitive Programming.

> **Learn → Practice → Track → Improve → Repeat**

---

## 🎯 Purpose

Starting DSA and Competitive Programming can feel confusing because there are too many resources available.

This repository provides a **simple and structured path**:

1. Learn programming fundamentals
2. Build problem-solving habits
3. Follow a structured DSA roadmap
4. Start Competitive Programming
5. Track your progress
6. Stay consistent

The goal is **not to complete resources as quickly as possible**.

The goal is to become a better problem solver.

# 📚 Recommended Resources

## 1️⃣ C Programming — College Wallah

Start with C programming if you are completely new to programming.

### Focus on

- Input / Output
- Variables & Data Types
- Operators
- Conditional Statements
- Loops
- Functions
- Arrays
- Strings
- Pointers
- Basic Problem Solving

### Resource

🎥 [C Programming Course — College Wallah](https://youtu.be/rQoqCP7LX60?si=ISpB4Z2qSxN96SyM)

### How to use it

**Don't just watch the lectures.**

For every topic:

```text
Watch → Understand → Code Yourself → Solve Problems
```

Try writing programs without copying the instructor's code.

# 2️⃣ DSA — TUF A2Z DSA Sheet

Once you are comfortable with programming fundamentals, start DSA using **Striver's A2Z DSA Sheet**.

### Why?

It provides a structured progression from basic concepts to advanced DSA.
You can learn cpp syntax from anywhere.

### Major topics

- Arrays
- Sorting
- Binary Search
- Strings
- Recursion
- Linked Lists
- Stack & Queue
- Sliding Window
- Greedy
- Trees
- Binary Search Trees
- Graphs
- Dynamic Programming
- Tries
- And more

### Resource

🌐 [Take U Forward — A2Z DSA Sheet](https://takeuforward.org/)

### Recommended approach

For every problem:

```text
1. Understand the problem
2. Think for yourself
3. Try to solve it
4. If stuck, study the approach
5. Implement it yourself
6. Understand the complexity
7. Revisit difficult problems later
```

> **Don't measure your progress only by the number of problems solved. Measure it by how much your problem-solving ability improves.**

---

# 3️⃣ Competitive Programming — CP-31

After building basic DSA skills, start Competitive Programming gradually.

**CP-31** is a useful problem list based on Codeforces ratings.

### What CP teaches you

- Problem-solving under time pressure
- Thinking about constraints
- Identifying patterns
- Implementation speed
- Mathematical thinking
- Greedy thinking
- Constructive problem solving
- Learning from unfamiliar problems

### Resource

🌐 [CP-31 Sheet](https://www.tle-eliminators.com/cp-sheet)

### Recommended approach

Start from a comfortable rating level and gradually move upward.

After every contest:

```text
Contest
   ↓
Check unsolved problems
   ↓
Try again
   ↓
Read editorial / solution
   ↓
Understand the idea
   ↓
Implement yourself
   ↓
Upsolve
```

### Important

**Don't be afraid of getting wrong answers or being unable to solve a problem.**

That is part of learning Competitive Programming.

# 4️⃣ Codolio — Track Your Progress

Use **Codolio** to keep your coding journey organized.

### You can use it to

- Track solved problems
- Track DSA progress
- Track coding profiles
- Organize your problem-solving journey
- Identify weak areas
- Maintain a visible record of your progress

### Resource

🌐 [Codolio](https://codolio.com/)

### Suggested habit

Update your progress regularly instead of trying to remember everything later.

# 5️⃣ Notion — Productivity & Planning

Use **Notion** to organize your learning.

🌐 [Notion](https://www.notion.com/)

You don't need a complicated productivity system.

Create something simple:

```text
📌 Weekly Goals

☑ DSA
☑ Competitive Programming
☑ Revision
☑ College Work

📚 DSA Notes

⚠️ Mistakes / Important Problems

📅 Weekly Review
```

### Remember

> **Productivity tools should help you study — not become another thing to study.**

Don't spend hours designing the perfect Notion dashboard.
